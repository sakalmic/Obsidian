# Project / Paper 1: Core LTSG Study

## Manuscript objective
Publish the reproducible core result of the PhD: how measured laser-channel variables and high-voltage working coefficient affect breakdown probability, delay and jitter, with synchronized diagnostics, uncertainty and an independently repeated confirmation. Select the journal only after the result and audience are clear; journal quartile and impact metrics must be checked at submission time.

## Evidence gate

Do not begin a results narrative until WP4 has produced one independently repeated effect and the timing/measurement budget is frozen. Negative or bounded results remain publishable if the protocol and statistical power are strong.

## Actionable tasks and timing

- [ ] **Sep 2026-Jan 2027:** freeze research question, outcome definitions, protocol and data schema during WP0-WP1.
- [ ] **Feb-Jun 2027:** build the methods text and figure templates from WP2-WP3; predeclare the confirmatory contrast.
- [ ] **Jul-Oct 2027:** acquire WP4 data and run quality-control reports without changing acceptance rules post hoc.
- [ ] **Nov 2027-Jan 2028:** fit the reduced model, validate it on held-out data and create the complete results package.
- [ ] **Feb 2028:** repeat the main result in an independent session and freeze the analysis version.
- [ ] **Mar 2028:** complete manuscript, internal reproducibility review and supervisor/co-author review.
- [ ] **By 30 Apr 2028:** submit to the journal selected from scope and completed evidence.

## Minimum figure set

1. apparatus, grounding and synchronized timing chain;
2. self-breakdown baseline and definition of $k$;
3. laser-channel calibration and measured operating space;
4. breakdown-probability model with uncertainty;
5. delay/jitter distribution including censored shots;
6. held-out or independent-session validation.
