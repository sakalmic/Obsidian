# CL-05 - Reduced predictive model

## Claim

A reduced model combining local $E/N$, electron-balance timescales and a measured or parameterised gas-density/channel state predicts at least one core observable under conditions not used for calibration.

## Candidate predicted outcomes

Choose one primary outcome before validation:

- breakdown probability within the trigger gate; or
- median/characteristic delay.

## Required evidence

- declared calibration and validation partition;
- parameter table with measured, literature-derived and fitted values distinguished;
- uncertainty and sensitivity analysis;
- comparison with a simpler empirical baseline;
- untouched validation condition or independent session.

## Decision rule

Specify prediction tolerance and interval-coverage target before opening the validation results. If the model fails, document the failure region and retain the smallest useful bounded model rather than adding unconstrained complexity.
